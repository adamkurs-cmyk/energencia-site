Cookie Policy

Last updated: 2 August 2026

Right now

This website does not set any cookies and does not use any analytics, advertising, or tracking technology. It's plain HTML and CSS with no third-party embeds, so no cookie banner is shown — under Spain's ePrivacy rules (LSSI-CE Art. 22) and GDPR, a consent banner is only required once something is added that stores information in your browser beyond what's strictly necessary to display the page.

What counts as a cookie here

A cookie (or similar technology — local storage, tracking pixels) is a small piece of data a website can store in your browser, e.g. to remember a preference or measure visits.

Applying to the training

The "Apply" button is a plain link to a Google Form — it opens Google's own site in a new tab rather than loading a form inside this page, so it does not itself set any cookies here. Google's own cookie and privacy policies apply once you're on their site.

Your choices

If this changes — for example if analytics is added later to see how the site is doing — this page will be updated first, with a consent step added before anything loads and a description of exactly what's stored and why.
